# 全流程验收清单（发布前最后一道关）

> 目的：用一个「没参与过开发的人」的眼睛，从零走一遍完整流程。
> 方式：**Chrome 无痕窗口**（或另一台电脑/手机）→ 打开制作向导 → 照下面做。
> 每步看「预期结果」，符合打 ✓，不符合记录现象发回。

## 准备

1. 双击 `start.command`（mac）/ `start.bat`（win），浏览器自动打开制作向导 `http://127.0.0.1:8765/builder/`
2. 按 `⌘+Shift+N`（Chrome 无痕）或直接换一台设备访问同一个地址

## A. 向导流程（约 10 分钟）

| # | 操作 | 预期结果 | ✓ |
| --- | --- | --- | --- |
| A1 | 点「🎈 从示例旅程开始」 | 进入「主角与封面」，名字显示「欣」 | ☐ |
| A2 | 把名字改成你自己的昵称；天数选 5 | 日期行变成 5 行；顶部下一步可点 | ☐ |
| A3 | 点一张风格卡（森林），再点回来 | 卡片有选中态；无报错 | ☐ |
| A4 | 封面大图「用自己的照片」传一张图 | 缩略图立即出现在选择位 | ☐ |
| A5 | 到「行程与文案」，展开第一站 | 表单可编辑、无乱码 | ☐ |
| A6 | 改站名与一段正文；「这一站的照片」连传 2 张 | 两张都出现在照片墙（不覆盖） | ☐ |
| A7 | 站图标「📷 添加贴纸」传 2 张 → 点第二张 | 收藏格 2 张并存；点谁谁成为当前图标 | ☐ |
| A8 | 某张贴纸点右上 ✕ | 只删那一张 | ☐ |
| A9 | 「预览与导出」 | 预览自动生成，可在预览里点开旅程 | ☐ |
| A10 | 点「💾 导出成品 HTML」 | 浏览器下载 birthday-trip.html | ☐ |

## B. 成品验证

| # | 操作 | 预期结果 | ✓ |
| --- | --- | --- | --- |
| B1 | 双击下载的 html | 打开的是你的主角名与所选风格 | ☐ |
| B2 | 封面「让故事开始」→ 地图 | 站点可见、第一步可进入 | ☐ |
| B3 | 一路点到终章（可刷新后再玩） | 解锁进度本地保存 | ☐ |
| B4 | 照片墙与「回忆册」 | 你传的照片都在，说明文字正确 | ☐ |
| B5 | 点右上音乐按钮 | 有旋律声；再点关闭 | ☐ |

## C. 换设备 / 换浏览器（可选但推荐）

| # | 操作 | 预期结果 | ✓ |
| --- | --- | --- | --- |

| C2 | 换一个浏览器（如 Safari / Edge）打开向导传一张照片 | 能成功（或出现清楚的原因提示） | ☐ |
