## 关于「生日快乐」类

- 《Happy Birthday to You》旋律（1893）已属公有领域；歌词在美国 2016 年诉讼后也被认定进入公有领域，但各地认定仍有差异 → **可以用，但建议标注来源**。目前站点主题曲已用你提供的 Birthday 主题曲，无需再找。

## 下载源（按推荐顺序）

1. **Musopen**（https://musopen.org/）—— 非营利组织，提供**公有领域古典录音**免费下载，最省事、最安全。
2. **classicals.de**（https://www.classicals.de/）—— PD 古典录音。
3. **Internet Archive**（https://archive.org/）—— 大量 PD 录音，搜索时勾选 license 为 Public Domain。
4. **Pixabay Music**（https://pixabay.com/music/）—— CC0/免版税，适合找「轻音乐」版本。
5. **Free Music Archive** —— 选 CC0 授权的曲目。

> IMSLP 只有**乐谱**，没有录音，不要在那里找音频。

## 交付方式（发给我时）

- 命名：`主题-曲名.mp3`，例如 `森林-晨曲.mp3`、`圣诞-平安夜.mp3`
- 每首一个版本即可，优先**钢琴 / 弦乐 / 小编制**（背景音乐不抢戏、体积也小）
- 时长 60–120 秒最合适（内嵌按 96kbps 算：每分钟约 700KB）
- 格式 mp3 / m4a / wav 都行
- 如果来源要求署名（CC BY 等），把来源链接一起发我，我会写进仓库的署名文件

## 我拿到文件后会做什么

1. 转码统一到 96kbps 单声道或立体声、按需裁切到合适长度
2. 放到 `assets/music/`，更新向导曲库（名称 + 主题标签 + 试听）
3. 在 `docs/CREDITS.md` 里登记来源与授权
4. 重跑 `python3 scripts/build-template.py`，让向导内嵌、试听、导出都能用
