# 文案写作指南

一份惊喜旅程网页的「灵魂」是文字。工具负责把版式做得漂亮，文案负责让对方读到的时候心头一暖。
这份指南给不会写、或想写得更好的你。

## 一、写之前：想清楚三件事

1. **这段旅程是给谁的？** TA 喜欢被叫的名字、TA 的口头禅、TA 会会心一笑的小梗——都值得放进去。
2. **这次旅程最想留住的 3 个瞬间是什么？** 一餐、一次出发、一场烟花……选最有画面感的。
3. **TA 打开时会在什么场景？** 通常是一个人、安静、手机屏幕亮着。文字要像在 TA 耳边说话。

## 二、每一站怎么写（5 个层次）

每站由这些部分组成，按顺序填，不会写就只填前两个：

| 部分 | 作用 | 写法建议 |
| --- | --- | --- |
| 站名（title） | 地图上那一站的名字 | 用一个有画面感的词：暖红小灶 / 光影放映厅 / 月光礼物站 |
| 一句话简介（short） | 地图面板上的预览 | 一句话告诉 TA 这一站会发生什么 |
| 正文（story） | TA 停留时逐段读 | 3 段左右：发生了什么 → 你的感受 → 一句悄悄话 |
| 心情（mood） | 情绪点题 | 一句像诗又像闲聊的总结 |
| 小任务（task） | 让 TA 参与 | 拍照、许愿、保存票根……越具体越动人 |

**正文写作口诀：** 写具体的事，不写空泛的话。
- 不好：今天的行程很开心，我们一起创造了很多美好回忆。
- 好：汤底咕嘟咕嘟地滚，我们边吃边聊，把想说的话都拌进蘸料里。

**多写「你」和「我们」，少写「我」。** 这是给 TA 的礼物。

## 三、几个通用句子库（可替换使用）

- 站名灵感：初见小馆 / 沿着风的路 / 星光收容所 / 慢慢喝的下午 / 篝火与信
- 结尾悄悄话：最好的告别，是下次再见。 / 有些话不必说出口，戴在手上就够了。
- 心情句模板：如果 ____ 有名字，它大概就叫 ____。

## 四、用 AI 帮你写（推荐）

在向导的「AI 助手」里（或任何聊天 AI，如 DSH / DeepSeek 网页版 / ChatGPT）粘贴下面这段话，
再把你的想法告诉它，它会返回一段可直接导入的 JSON：

```
你是我的文案助手。我准备做一份「生日/纪念日旅行惊喜网页」，请你帮我把下面的口述安排成 3-6 站旅程文案。
要求：中文、浪漫、具体、像对 TA 说悄悄话；不要空泛口号；不要编造真实姓名（用昵称）。
请只返回 JSON，结构：{"hero": {...}, "stops": [{"day":1,"title":"站名","short":"一句话","story":["段1","段2","段3"],"mood":"一句心情","task":"小任务","hint":"第 n 张卡"}], "dayDates": {...}}
然后把我下面的话写进去：
【在这里描述你们的行程：几天、去了哪、有什么想留住的瞬间】
```

拿到 JSON 后：向导「AI 助手 → 粘贴导入」贴进去即可；回来后仍可在「行程与文案」逐站微调。

**小技巧：** AI 第一版通常不够像「你们」。把它写好的某站贴回去，追加一句
「这站改成……的语气，提到 TA 喜欢的那件事」，多打磨一两轮会自然很多。

## 五、发布前自查

- 通读每一站正文：删掉任何不像你们会说的话。
- 有没有一处地方能让 TA 读到这里时笑出来 / 眼眶热一下？
- 照片配文别写「照片 1」：写当时发生了什么（“海边那天的风很大，我们笑了很久”）。
