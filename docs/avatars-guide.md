# 小人（落款 / 地图主角）出图提示词指南

> 引擎里的两位小人是「封面落款头像」，也是「地图上沿路线一站一站走的主角」。
> 每个用户都可以换成自己的一对小人物：`assets/avatars/` 放图 → 向导「主角与封面 → 落款头像」里点选/上传。
> 本指南用于给即梦 / 豆包等工具批量生成「同一对主角、多主题换装」的系列小人。

## 参考形象（一对马卡龙粉白 Q 版小王子 / 小公主）

- **小王子（男孩）**：暖棕蓬松短发、圆脸；米白底粉镶边上衣、领口粉蝴蝶结、胸口爱心四叶草小饰；粉色短披风；挥手微笑。
- **小公主（女孩）**：浅粉双马尾（带光泽）、头顶金色心形小皇冠；米白底粉蕾丝洛丽塔连衣裙（泡泡袖、收腰、多层荷叶边裙摆）、腰间粉蝴蝶结；右手持粉色心形魔法棒；活泼灵动。
- **共同画风**：Q 版约 1:2 头身、头大身小、线条圆润、深色细描边、水彩+扁平、柔和渐变、低饱和暖色调。

## 固定段（每次生成都原样保留，保证同一位主角）

小王子固定段：
`Q版卡通男孩，暖棕色蓬松短发，圆脸大眼睛，米白色上衣带粉色镶边，领口粉色蝴蝶结，胸前爱心与四叶草小装饰，粉色短披风，微笑挥手`

小公主固定段：
`Q版卡通女孩，浅粉色柔顺双马尾，发顶金色心形小皇冠，米白色洛丽塔连衣裙带浅粉蕾丝与荷叶边裙摆，腰间粉色蝴蝶结，手持粉色心形魔法棒，微笑灵动`

固定画风尾段：
`Q版约1:2头身比，线条圆润，深色细描边，水彩扁平插画，柔和渐变，低饱和暖色调，构图居中头部不裁切。无文字、无水印、无logo、无真实人脸、非照片`

## 通用要求

- 每套生成 **两张独立单人图**（两人要在地图上分开移动，不能一张双人同框）。
- 背景用**浅色渐变圆形底**（米白到主题色极浅），小图与深色地图上都清晰；可加两三个呼应主题的极淡小元素。
- 发色 / 皇冠 / 魔法棒是识别核心，尽量保留；只有服装配色与背景元素随主题变化。

## 主题变装段（替换颜色即可）

### ① 森林（鼠尾草绿 / 焦糖）

### ④ 圣诞颂歌（松针绿 / 红 / 金）
`服装换成圣诞配色：男孩米白上衣配墨绿色披风与正红围巾，女孩裙摆与蝴蝶结改为正红蕾丝、发间别墨绿蝴蝶结，背景极浅冷白到米白渐变圆形底，落下两三颗淡金小雪点`

## 交付与入库

1. 即梦按「固定段 + 一个主题变装段 + 固定画风尾段」逐套生成，每套挑两张独立单人图。
2. 把文件路径发给项目维护者（或自行放入 `assets/avatars/`），在向导 `AVATAR_SETS` 加一行套装（label + 两枚文件 key）。
3. 引擎 / 素材改动后重跑 `python3 scripts/build-template.py`。
