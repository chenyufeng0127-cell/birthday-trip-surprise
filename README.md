# Birthday Trip Surprise

一个可以**自己填空定制**的生日 / 纪念日「惊喜旅程」互动网页模板。

> ⚠️ 本项目正在从个人定制版改造成通用开源模板（进行中）。
> 当前目录为**引擎骨架**：代码 + 示例插画/图标/地图素材，不含任何个人照片。

## 这是什么

一段可以发给对方、在手机里慢慢展开的互动旅程：

- 封面 → 逐站解锁的路线地图 → 每一站的故事、任务、小卡片、骰子小游戏 → 终章 → 「旅程纪念版」照片收集册
- 全程零依赖、零后端、零构建：纯 HTML + CSS + JS，双击 `index.html`（或任意静态托管）即可运行
- 音乐为浏览器内置合成（Web Audio），无需任何音频文件

## 目录结构（目标形态）

```text
birthday-trip-surprise/
├── index.html      # 页面骨架（壳）
├── config.js       # ★ 唯一需要你改的文件：主角、日期、每一站、照片清单、主题
├── app.js          # 引擎逻辑
├── styles.css      # 样式（含主题变量）
└── assets/         # 示例素材：ai/（插画）icons/（图标）map/（地图）photos/（你自己的照片，git 忽略）
```

## 快速开始（配置式模板定稿后更新）

1. 把你的照片放进 `assets/photos/`
2. 打开 `config.js`，照着注释填写主角名、日期、每一站的名字/文案/照片文件名
3. 双击 `index.html` 预览，或用任意静态托管部署

## 隐私说明

- 本仓库**不会也不应**包含任何真实人物照片/视频，`.gitignore` 已做硬性拦截。
- 你的个人素材请保存在本地或自己的私有仓库；公开发布前请自行核对。
- 仓库内 `assets/ai` 为示例插画（AI 生成），可在你的定制中替换或删除。

## 技术备注

- 支持 `?preview=1`（全部解锁）、`?view=chapter&stop=2`、`?selftest=1`（回归自检）等调试参数
- 适配移动端优先，桌面亦可用
