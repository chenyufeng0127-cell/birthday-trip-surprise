# Birthday Trip Surprise 🎈

一个**不用写代码**就能做的「惊喜旅程」互动网页：选主角、写/让 AI 写行程文案、放照片、导出成品——把成品文件发给 TA，对方打开就能一站一站解锁你们的故事。

> ⚠️ 开发中。当前已可用：示例成品站 + 制作向导（编辑/照片/AI 草稿/单文件导出）。
> 本仓库不含任何真实人物照片与视频。

## 怎么打开

**最简单（推荐）：双击一键启动器**（自动起本地服务并在浏览器打开制作向导）

- macOS：双击 `start.command`（首次若被系统拦截，右键 → 打开）；
- Windows：双击 `start.bat`（需要装 Python）。

启动后浏览器会打开制作向导：`http://127.0.0.1:8765/builder/`

**备用方式（不启动服务，直接双击网页文件）**

| 你想做什么 | 打开哪个 |
| --- | --- |
| 现场看成品效果 | 双击根目录 `index.html` |
| 制作你自己的惊喜旅程 | 双击 `builder/index.html`（制作向导） |

> 直接用浏览器打开本地网页（file://）在 Chrome / Edge 上通常没问题；个别浏览器或系统对本地网页有限制，遇到打不开/白屏就用上面的启动器方式，最稳。

### 制作向导（推荐给所有人）

`builder/index.html` 是纯本地网页，双击即可使用（无需安装、无需联网、不上传任何数据）：

1. **开始**：从「示例旅程」开始改，或从空白搭建；
2. **主角与封面**：名字、日期、标题、封面图、落款、旅程天数、地图背景；
3. **行程与文案**：一站一站编排（第几天 / 站名 / 正文 / 心情 / 小任务 / 骰子卡片 / 图标 / 大图 / 照片墙），照片可以从手机相册或本地选择，自动压缩保存在本机；
4. **AI 助手**：两种用法——
   - 填你自己的 DeepSeek API Key 直接在向导里对话，让 AI 按口述行程起草；
   - 复制内置提示词，发给任意 AI（DSH / DeepSeek 网页版 / ChatGPT），把返回的 JSON 粘贴回来导入；
5. **预览与导出**：实时预览成品，导出一个**自包含 .html 文件**（照片全部内嵌），发给 TA 双击/浏览器打开即可，无需联网。

草稿自动保存在浏览器本地（localStorage + IndexedDB），关掉再打开可以继续。

## 仓库结构

```text
birthday-trip-surprise/
├── index.html / config.js / app.js / styles.css   # 成品引擎（也是示例成品）
├── assets/
│   ├── ai/ icons/ map/ photos/sample/             # 内置示例素材（无隐私）
│   └── photos/                                    # 你的照片目录（git 忽略）
├── builder/                                       # ★ 制作向导（无需改代码）
│   ├── index.html / builder.js / builder.css / builder-media.js
│   └── template.inline.js                         # 引擎内联资源（脚本自动生成）
└── scripts/build-template.py                      # 重新生成 template.inline.js
```

高级用法：也可以不打开向导，直接改根目录 `config.js` 后双击 `index.html`——引擎与向导生成的是同一套配置。

## 隐私说明

- 本仓库**不会也不应**包含任何真实人物照片/视频；`.gitignore` 做了硬性拦截。
- 向导里的一切（草稿、照片、AI Key）都只保存在使用者自己的浏览器里，不会上传到任何服务器。
- 你的个人素材请保存在本地或自己的私有仓库；公开发布前请自行核对。
- 若修改了成品引擎（根目录三件套）或素材，请运行 `python3 scripts/build-template.py` 重新生成向导内联资源。

## 技术备注

- 成品站调试参数：`?preview=1`（全部解锁）、`?view=chapter&stop=2`、`?selftest=1`（回归自检）
- 向导自检：`builder/?selftest=1`（构建导出）、`builder/?e2e=1`（内联成品实跑验证）
- 零外部依赖：纯 HTML/CSS/JS；音乐为浏览器内置合成（Web Audio）
- 移动端优先，桌面亦可用
